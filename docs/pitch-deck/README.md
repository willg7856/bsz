# Beyond Stage Zero — Sponsor Pitch Deck

11-slide, 16:9 sponsorship pitch deck for industry, education, and community partners.

## Files

| Path | Purpose |
|------|---------|
| `index.html` | Slide content (open in a browser to present) |
| `deck.css` | Brand-matched layout |
| `assets/` | Logo, B1M CAD, partner marks used by the deck |
| `../BSZ-Sponsor-Pitch-Deck.pdf` | Export ready to send |

## Regenerate the PDF

```bash
./scripts/generate_sponsor_pitch_deck.sh
```

Requires Google Chrome. Output: `docs/BSZ-Sponsor-Pitch-Deck.pdf`.
